# CMS v1.6.x UI卡死问题完整排查记录

## 背景

CMS（Character Memory System）无 worker 版本出现 UI 卡死、无响应，严重时导致 App 闪退。

本报告记录从 v1.6.0 到 v1.6.9 的完整定位过程。

------------------------------------------------------------------------

# 第一阶段：加载链问题

## v1.6.0

目标：

修复 loadPersona 重复执行。

结果：

-   加载锁生效
-   loadPersona 风暴停止
-   UI卡死仍存在

结论：

异步加载链不是最终原因。

------------------------------------------------------------------------

# 第二阶段：排除状态污染

## v1.6.1

实验：

useState/useRef key 增加 namespace（cms_ 前缀，防与 CME 同源 key 全局污染）。

结果：

仍卡死。

结论：

state key 污染不是主要原因。

------------------------------------------------------------------------

# 第三阶段：排除UI规模和内容

## v1.6.2

实验：

87条记忆减少到10条。

结果：

仍出现高频 mount。

结论：

不是节点数量导致。

------------------------------------------------------------------------

## 共存实验

测试：

| 环境 | 结果 |
| --------- | --------- |
| CME单独 | 正常 |
| CMS单独 | 卡死 |
| CMS+CME | CMS卡死 |

结论：

排除插件共存冲突。

------------------------------------------------------------------------

## v1.6.4

实验：

固定persona和memory文本。

结果：

仍卡死。

结论：

不是数据内容问题。

------------------------------------------------------------------------

# 根因定位实验

## v1.6.6

静态页面：

    Text("hello")

结果：

正常。

证明：

-   Screen生命周期正常
-   平台渲染入口正常

------------------------------------------------------------------------

## v1.6.7

完整UI结构：

-   persona卡片
-   memory列表
-   Button
-   Icon
-   Surface

无：

-   setState
-   load
-   异步副作用

结果：

正常。

结论：

UI结构排除。

------------------------------------------------------------------------

## v1.6.8

唯一增加：

render阶段：

    personaState[1](固定值)

结果：

立即出现 mount 风暴。

结论：

根因确认：

> render阶段调用state setter导致无限重建。

------------------------------------------------------------------------

# 根因模型

    render()
     ↓
    setState()
     ↓
    XML重新生成
     ↓
    liveXmlContent变化
     ↓
    LaunchedEffect重启
     ↓
    Screen重新执行
     ↓
    render再次setState

------------------------------------------------------------------------

# v1.6.9修复

原则：

render必须纯函数。

改为：

    onLoad/action
     ↓
    加载数据
     ↓
    setState
     ↓
    render纯读取
     ↓
    生成UI

结果：

-   mount正常
-   tab切换正常
-   角色页稳定

------------------------------------------------------------------------

# Operit Compose DSL铁律

1.  render禁止任何setState
2.  render禁止启动加载
3.  UI构造阶段禁止副作用
4.  数据同步必须发生在生命周期/action阶段
